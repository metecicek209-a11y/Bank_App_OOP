A small console banking app I built to practice OOP in C#.

Features
- Create 2 different kind of account
- Deposit and withdraw
- Check balance

## OOP concepts I used
- Encapsulation (private balance, changed only through methods)
- Inheritance 

## Run
Open the solution in Visual Studio and run the project.
Used directly from the console no ui exists yet.
